# 柚铃随机表情包

AstrBot 分类随机表情包插件：群聊提到作品或角色名称即可发图，支持本地图库、网页批量上传、自定义分类，以及收集候选表情后人工审核入库。

## 功能

- **提到 IP 自动发图**：无需 @或命令；一句多个分类只选择最先出现的一个，每次只发一张。
- **统一图库**：本地图片优先，没有本地图片的在线分类按需读取公开索引；支持 `/pig`。
- **网页管理**：批量上传、新增分类、设置触发词、查看本地与在线数量。
- **随机偷表情**：平台明确标记优先；无可靠标记时可用已配置的视觉模型识别，成功保存后才回复“你这个表情包不错，我偷走了”。
- **审核后入库**：候选图与正式图库分离，选择分类并审核通过后才能参与抽图。
- 自动触发有冷却及同群取图保护；不吞掉包含 IP 名称的正常 @聊天。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| AstrBot | `>=4.28,<5`，在 4.28.2 验证；使用原生插件网页与 Web API |
| Python | 3.12 或更高，遵循 AstrBot 的环境要求 |
| 平台 | QQ 官方接口 `qq_official`、OneBot `aiocqhttp` |
| Python 依赖 | `aiohttp`、`Pillow`，见 `requirements.txt` |
| 网络 | 在线分类首次拉取索引需访问 GitHub，下载图片需访问图片源；纯本地分类无需联网取图 |

## 安装

在 AstrBot 后台的插件页面选择“从链接安装”，填写：

```text
https://github.com/Kimari-0523/astrbot_plugin_yueling_random_meme
```

也可下载仓库 ZIP 后从文件安装。手动部署时，在 AstrBot 使用的 Python 环境运行：

```bash
python -m pip install -r requirements.txt
```

启用插件后，打开原生插件页面 **“表情包上传”**。

**本公开仓库不附带任何用户图片或完整图库。** 时雨羽衣、猪猪等纯本地分类首次安装显示 0 张属于正常情况，需要自行上传有权使用的图片；原部署机器的图片和自定义分类不会因为这个源码仓库自动同步。

## 指令与触发

| 方式 | 示例 | 说明 |
| --- | --- | --- |
| 群聊普通文字 | `我喜欢初音未来`、`MyGO 真好看` | 提到启用分类或别名即抽一张 |
| 分类菜单 | `/随机表情包`、`/随机表情包 2` | 分页查看分类 |
| 全部 IP | `/表情包IP列表` | 列出已启用分类与触发词 |
| 指定分类 | `/随机表情包 初音` | 按名称或别名抽图 |
| 随机分类 | `/随机分类表情包` | 随机选分类后抽图 |
| 分类快捷指令 | `/随机初音`、`/随机mygo`、`/随机妈妈` | 使用该分类及其别名 |
| 猪猪兼容 | `/pig`、`/pig status`、`/pig update` | 抽本地图、查数量、扫描本地图片 |

初音未来和 Fufu 使用同一分类。内置在线分类包括孤独摇滚、MyGO、兽耳酱、狗妈、蔚蓝档案、柴郡猫、柚子社、Doro、Eveonecat、甘城猫猫、少女乐队的呐喊、咖波、吉伊卡哇等，以 `/表情包IP列表` 实际结果为准。

时雨羽衣别名包含“时雨羽衣、時雨羽衣、しぐれうい、ういママ、妈妈、妈咪、麻麻”等，短词可能误触，可在后台禁用相应分类。自定义分类可自行增加 AI 模型名或其他作品名；仓库不包含任何运行实例的自定义分类数据。

英文不区分大小写，英文别名按单词边界匹配，纯数字索引别名不自动触发。自动匹配只看本轮文字，不读取引用内容、不做 OCR；其他 `/` 或 `／` 开头的命令不参与自动匹配。私聊只支持手动命令。

## 网页上传与新增分类

在“表情包上传”页选择分类，批量选图并上传；点击“新增分类”可添加分类名称和触发别名，分类名称本身也会触发。上传后无需重载。

- 每批最多 100 张，每张最多 8 MiB。
- 支持 JPG、PNG、GIF、WebP；逐帧检查完整性，WebP 转 PNG／GIF，保留支持的动画。
- 内容哈希去重，不使用上传者文件名拼接路径。
- 最多 100 个自定义分类，每类最多 64 个触发名称。
- 正式本地图库上限 512 MiB；禁用分类上传后仍保持禁用。
- “本地 0 张”不代表在线分类失效；在线条数只是索引记录数，不保证每个远程链接有效。

网页接口沿用 AstrBot 后台登录与访问权限，不需要新端口或额外匿名上传接口。

## 随机偷表情与审核

插件配置可独立开关收集、设置采样概率、每群间隔、群白名单和视觉提供商 ID。

| 设置 | 默认值 |
| --- | --- |
| 收集开关 | 开 |
| 随机采样 | 20% |
| 每群尝试间隔 | 120 秒，可调 10—3600 秒 |
| 群白名单 | 空，表示全部群 |
| 无明确标记时识图 | 开 |
| 视觉提供商 ID | 空，跟随当前聊天模型 |

仅群聊，每条消息最多收集一张，不收集机器人自己的图片。OneBot 的明确普通图片标记会跳过；QQ 官方接口一般没有可靠区分标记，此时需要支持图片输入的模型。只有明确判定为表情且成功保存才发送收集提示；普通照片、截图、文档、壁纸、不确定、重复、识别失败或冷却中的图片均可能静默跳过。100% 概率不等于保证每张图入队。

候选图进入“偷来的表情 · 待审核”，选择分类并“通过并入库”后立即生效；“忽略”会标记并保留审核存档，避免重复收集。最多 200 张待审核，审核存档总上限 128 MiB，达到上限暂停收集。

**隐私说明：** 无明确平台标记时，候选图片的低分辨率预览会发送给所选视觉模型；插件不附带聊天历史或群身份给识图请求。候选图和群／发送者去重元数据保存在部署实例的数据目录。部署前请按所在群的规则告知成员，并选择合适的收集开关与白名单。所有服务账户仍只在 AstrBot 中自行配置。

## 数据与配置

运行数据写入 `data/plugin_data/astrbot_plugin_yueling_random_meme/`：

```text
indexes/          在线索引缓存
cache/            下载图片缓存
local/<分类ID>/   本地正式图库
categories.json   自定义分类和别名
review/           待审核、审核存档及去重记录
```

更新前建议按需备份实例的数据目录。公开仓库不会上传这些文件、账号配置、密钥、日志或你的私人图库。

## 常见问题

- **刚安装的时雨羽衣／猪猪不发图**：纯本地分类不附带图片，先在网页上传。
- **在线分类偶尔失败**：检查网络、GitHub API 限制和原图源；插件最多换图重试 3 次，自动触发失败时静默跳过。
- **偷表情没有回应**：检查采样、冷却、重复记录、平台标记、视觉模型能力及待审核容量，后台可查看最近尝试状态。
- **@机器人没有文字回答**：本插件不会主动停止聊天；检查 AstrBot 的唤醒规则、其他回复插件与聊天提供商。
- **想加 Claude、GPT 等 AI 分类**：新增名为“AI”的分类，把模型名填入触发别名，再上传自己的图片。
